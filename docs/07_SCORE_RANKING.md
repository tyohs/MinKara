# 07. スコア・ランキング

## 7.1 スコアシステム概要

MinKaraのスコアは、**バンド役のリズムゲーム判定**をベースに計算します。  
基本仕様では、スコアはバンドのみが獲得し、リザルト画面で表示します。

---

## 7.2 スコア計算（基本仕様）

### バンドのスコア

| 判定 | 基本点 | コンボボーナス |
|------|--------|---------------|
| PERFECT | 100 | × (1 + combo/100) |
| GREAT | 75 | × (1 + combo/100) |
| GOOD | 50 | × (1 + combo/100) |
| MISS | 0 | コンボリセット |

### 計算式
```
スコア = 基本点 × (1 + combo数 / 100)
```

### 例
- PERFECT、コンボ50の場合:
  ```
  100 × (1 + 50/100) = 100 × 1.5 = 150点
  ```

## 7.3 役割別スコアリング

### 基本仕様

| 役割 | スコア計算方法 |
|------|--------------|
| **バンド** | リズム判定に基づく（上記） |
| **シンガー** | 曲完走ボーナス（固定1000点） |
| **お邪魔** | アクション1回につき固定50点 |

## 7.6 データ保存（Supabase）

### テーブル構成

#### `game_sessions`
曲ごとのセッション情報

```typescript
interface GameSession {
  id: string;              // UUID
  room_id: string;         // ルームID
  song_id: string ;        // 曲ID
  singer_id: string;       // シンガーのユーザーID
  started_at: timestamp;   // 開始時刻
  ended_at: timestamp;     // 終了時刻
  total_score: number;     // 総合スコア
}
```

#### `scores`
個人スコア詳細

```typescript
interface Score {
  id: string;              // UUID
  session_id: string;      // セッションID
  participant_id: string;  // 参加者ID
  role: 'singer' | 'band' | 'ojama';  // 役割
  score: number;           // スコア
  perfect_count: number;   // PERFECT数（バンドのみ）
  great_count: number;     // GREAT数（バンドのみ）
  good_count: number;      // GOOD数（バンドのみ）
  miss_count: number;      // MISS数（バンドのみ）
  max_combo: number;       // 最大コンボ（バンドのみ）
}
```

## 7.7 スコア同期

### Supabase Realtime
- リアルタイムでスコアを同期
- 全プレイヤーが同じスコアを見る

### 実装例
```typescript
// スコア更新をブロードキャスト
supabase.channel('room:123')
  .on('broadcast', { event: 'score_update' }, (payload) => {
    updateScore(payload.participant_id, payload.score);
  });
```
