# 01. 概要・コンセプト

## 1.1 プロダクト名
**みんカラ**（MinKara）

---

## 1.2 コンセプト

**「音に乗ることを重視」** したカラオケ体験アプリ。

歌う人だけでなく、バンドやお邪魔役として**全員が音に乗って参加**できる。  
Bluetoothスピーカーに繋げばさらに盛り上がる、**身内パーティ向けアプリ**。

---

## 1.3 解決する課題

| 従来のカラオケ | みんカラ |
|---------------|---------|
| 歌わない人は暇 | バンド・お邪魔で全員参加 |
| 一人だけが主役 | 全員が音に乗って楽しめる |
| リアクションが薄い | お邪魔やリズムゲームで盛り上がる |
| スマホいじりがち | ゲーム性で没入感UP |

---

## 1.4 配信形態

- **スタンドアロンWebアプリ**として動作
- **Supabase Realtime**でスコア・状態を同期
- **インターネット接続必須**

---

## 1.5 ターゲット

### メインターゲット
- カラオケで歌わない人が暇になりがちな友人グループ
- 3〜10人程度の身内パーティ

### サブターゲット
- 技育博などのイベントでのデモ展示
- カラオケ好きで新しい体験を求める層

---

## 1.6 主要機能（概要）

| 機能カテゴリ | 説明 |
|------------|------|
| **デンモク** | 曲予約・削除・順番変更・ルーレット |
| **シンガー** | 歌詞表示、応援コメント受信 |
| **バンド** | リズムゲーム（ギター/ドラム/キーボード） |
| **お邪魔** | 他プレイヤーを妨害する専用役割 |
| **スコア** | バンドの判定スコア、身内ランキング |

---

## 1.7 技術的特徴

- **Supabase Realtime**によるリアルタイム同期
- **Web Audio API**による音声再生
- **Glassmorphism**デザイン（寒色系）
- **Next.js 16 + React 19**による最新Web技術
