# 04. デンモク機能

## 4.1 概要

**デンモク画面**は、曲を予約・管理し、ゲームを開始するためのロビー画面です。  
従来のカラオケのリモコン（デンモク）をイメージした機能を提供します。

---

## 4.2 機能一覧

| 機能 | 説明 | 権限 |
|------|------|------|
| **曲の予約** | フリー音源リストから曲を選択して予約 | 全員 |
| **予約削除** | 自分が予約した曲をキャンセル | 予約者・ホスト |
| **順番変更** | ドラッグ＆ドロップで予約順を変更 | ホスト |
| **歌う人ルーレット** | ランダムで歌う人を決定 | ホスト |
| **参加者一覧** | 現在ルームにいる人を表示 | 全員 |
| **曲開始** | 予約リストの先頭曲をスタート | ホスト |

---

## 4.4 曲の予約

### 予約手順
1. 「曲を予約」ボタンをタップ
2. 曲リストから選択
3. 予約リストの最後尾に追加

### 曲リスト表示
| 表示項目 | 説明 |
|---------|------|
| **曲名** | 楽曲のタイトル |
| **アーティスト** | 歌手名 |
| **BPM** | テンポ |
| **ジャンル** | カテゴリ |

### 検索・フィルタ
- 曲名検索
- ジャンル絞り込み
- BPMソート

---

## 4.5 予約削除

### 削除ルール
1. **自分の予約**は自由に削除可能
2. **ホスト**は全ての予約を削除可能
3. 削除すると予約リストから即座に消える

### UI
- 予約リスト各項目に「✕」ボタン
- タップで確認ダイアログ表示
- 確定で削除

---

## 4.6 順番変更

### 変更方法
- **ドラッグ＆ドロップ**で順番を入れ替え
- **ホストのみ**実行可能

### リアルタイム同期
- 順番変更は全参加者に即座に反映
- Supabase Realtimeで同期

---

## 4.7 歌う人ルーレット

### 概要
- ランダムで次の曲のシンガーを決定
- **ホストのみ**実行可能

### 基本仕様

#### 対象
- 現在ルームにいる**全参加者**

#### 演出
1. 「ルーレット」ボタンをタップ
2. ルーレット演出（アニメーション）
3. 当選者を表示
4. 当選者が次の曲のシンガーになる

#### ルール
- ルーレットで決まった人は**自動的にシンガー**
- 拒否不可
- 通常予約とは別枠で管理

### 将来の拡張
- 重み付き（最近歌っていない人優先）
- オプトイン式（参加意思を表明した人のみ）
- 詳細は[将来の拡張機能](./10_FUTURE_FEATURES.md)参照

---

## 4.8 参加者一覧

### 表示項目
| 項目 | 説明 |
|------|------|
| **名前** | 参加者の名前 |
| **ステータス** | オンライン/オフライン |
| **ホストマーク** | ホストには👑アイコン |

### リアルタイム更新
- 参加者の入退室を即座に反映
- オンライン人数を常時表示

---

## 4.9 曲開始

### 開始条件
1. 予約リストに**1曲以上**ある
2. **ホスト**が「曲開始」ボタンを押す

### 開始時の処理
1. 予約リストの**先頭曲**を選択
2. 予約者（またはルーレット当選者）がシンガーになる
3. 他の参加者は役割選択画面へ遷移
4. 曲のロードと同期処理
5. カウントダウン後、プレイ開始

---

## 4.10 データ構造

### 予約リスト（Supabaseテーブル）

```typescript
interface Reservation {
  id: string;              // UUID
  room_id: string;         // ルームID
  song_id: string;         // 曲ID
  reserved_by: string;     // 予約者のユーザーID
  order: number;           // 順番
  is_roulette: boolean;    // ルーレット予約か
  created_at: timestamp;   // 予約日時
}
```
