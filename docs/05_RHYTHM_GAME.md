# 05. リズムゲーム

## 5.1 概要

バンド役のプレイヤーは、**リズムゲーム**で楽曲演奏に参加します。  
ノーツをタイミング良くタップして判定を獲得し、スコアを稼ぎます。

---

## 5.2 判定システム

### 判定種類

| 判定 | タイミング | 基本点 | 表示 |
|------|-----------|--------|------|
| **PERFECT** | ±50ms | 100 | 🌟 金エフェクト |
| **GREAT** | ±100ms | 75 | ✨ 銀エフェクト |
| **GOOD** | ±150ms | 50 | ⭐ 青エフェクト |
| **MISS** | それ以外 | 0 | 💀 赤エフェクト |

### コンボシステム
- 連続で判定に成功するとコンボ数が増加
- **MISS**でリセット
- コンボ数に応じてボーナス倍率
  ```
  スコア = 基本点 × (1 + combo/100)
  ```

---

## 5.3 ノーツ生成

### 基本方式：BPM自動生成
- 曲の**BPM（Beats Per Minute）** から自動的にノーツを配置
- 拍に合わせて均等配置
- 実装が簡単で曲追加が楽

### ノーツタイプ
| タイプ | 説明 | 出現頻度 |
|--------|------|---------|
| **通常ノート** | 基本のノート | 90% |
| **スペシャルノート** | 高得点ノート（⭐マーク） | 10% |

### スペシャルノートの特徴
- ヒット時に**画面全体が金色フラッシュ**
- パーティクルエフェクト発生
- **判定テキスト拡大** + 「✨」追加
- 通常の**1.5倍**のスコア

## 5.6 入力方式

### キーボード
- デスクトップ・ラップトップで使用
- 各楽器の指定キーで入力

### タッチ
- スマホ・タブレットで使用
- 画面タップで入力
- マルチタッチ対応（同時押し）

---

## 5.7 振動フィードバック（スマホのみ）

| 判定 | 振動パターン |
|------|-------------|
| PERFECT | 30ms |
| GREAT | 20ms |
| GOOD | 10ms |
| MISS | 100ms（長め） |

※ `navigator.vibrate()` APIを使用

---

## 5.8 難易度調整（将来実装）

基本仕様では**単一難易度**のみ。  
将来的に以下の難易度を検討：

| 難易度 | ノーツ密度 | 同時押し |
|--------|-----------|---------|
| Easy | 4分音符のみ | なし |
| Normal | 8分音符まで | 2つまで |
| Hard | 16分音符まで | 3つ以上 |

詳細は[将来の拡張機能](./10_FUTURE_FEATURES.md)参照。

## 5.9 データ構造

### ノーツデータ

```typescript
interface Note {
  time: number;        // ノーツのタイミング（ms）
  lane: number;        // レーン番号（0-5）
  type: 'normal' | 'special';  // ノーツタイプ
}

interface Chart {
  songId: string;      // 曲ID
  bpm: number;         // BPM
  notes: Note[];       // ノーツ配列
}
```
